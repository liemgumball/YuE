# Stem MIDI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split each song into Demucs stems, transcribe bass and other to MIDI on the ABC grid, and ship only the ABC MIDI plus the stem files.

**Architecture:** A new `tools/stem_midi.py` holds the pure logic (seconds→quarters, dropping notes before beat 0, writing MIDI through `abc_midi._track/_file`, trimming WAVs, reusing stems) with the two models passed in as functions, so the tests can use fakes. A small adapter module, `tools/stem_models.py`, wraps Demucs and basic-pitch. `sheetsage_midi.py` deletes SheetSage2's own MIDI files and calls the stem step on its own, failure-isolated.

**Tech Stack:** Python, mido, numpy, soundfile, demucs (`htdemucs`), basic-pitch (ONNX). Everything runs in `.venv-sheetsage2`.

**Spec:** `docs/superpowers/specs/2026-11-24-stem-midi-design.md`

## Global Constraints

- Outputs: `sheetsage2/bass.mid` (track "Bass"), `sheetsage2/other.mid` (track "Other"), `sheetsage2/stems/{drums,bass,other,vocals}.wav`.
- Keep `abc_melody.mid` and `abc_chords.mid`. Delete every `*.mid` that SheetSage2's `transcribe` reports in `r["midis"]`.
- No drum MIDI, no vocal-stem MIDI, no quantizing.
- If stem output fails, ABC output must still work, and the other way around.
- Tests run with: `.venv-sheetsage2\Scripts\python -m unittest discover -s tests -v`

## Review Focus

- No `events.json` (or fewer than 2 timestamps): fall back to plain seconds at the score BPM, or 120 without a score, and print a warning instead of crashing. Test in Task 2.
- No `score.abc` / `abc_error`: stems still render at 120 BPM. Test in Task 2.
- A note that starts before beat 0 but ends after it gets dropped entirely, not clipped. Test in Task 2.
- Stems already exist: the separate function is not called. Test in Task 2.
- `clock(0)` is negative (beat 0 falls before the audio starts): pad the start of the WAV with silence instead of failing. Test in Task 2.

### Task 2: `stem_midi.render` with injectable models

**Files:**
- Create: `tools/stem_midi.py`
- Test: `tests/test_stem_midi.py`

**Interfaces:**
- Consumes: `abc_midi._track(name, channel, notes, velocity)`, `abc_midi.PPQ`, `abc_tools.parse`, `midi_velocity.quarter_clock`, `seconds_to_quarters` (Task 1).
- Produces:
  - `Note = tuple[float, float, int, int]`, meaning (start_s, end_s, pitch, velocity)
  - `to_grid(notes: list[Note], to_q: Callable[[float], float]) -> list[tuple[float, int, float, int]]`, giving (start_q, pitch, length_q, velocity). Drops notes with `to_q(start_s) < 0`.
  - `render(song_dir, separate, transcribe) -> list[Path]`, where `separate(audio: Path, out_dir: Path) -> None` writes the four raw WAVs, and `transcribe(wav: Path, bass: bool) -> list[Note]`.
- Implementation notes:
  - Write a `_stem_file(bpm, track)` that's like `abc_midi._file` but takes a BPM directly (4/4 when there's no score). Extend `_track` to take a per-note velocity list. It already does.
  - Tempo: `score.bpm` from `sheetsage2/score.abc` if it parses, else 120.
  - Grid: `seconds_to_quarters(events)` from `events.json`. Otherwise use `lambda s: s * bpm / 60` and print `warning: no events.json, stem MIDI uses fixed tempo`.
  - Separation goes to `stems/raw/` (only when `stems/*.wav` are missing). Then each raw stem is trimmed so it starts at `clock(0)`, or padded with zeros if `clock(0) < 0`, and written to `stems/<name>.wav` with soundfile. The `raw/` folder is deleted afterwards. With no clock, copy the files unchanged.
  - Transcribe from the trimmed `stems/bass.wav` and `stems/other.wav`. Note times then count from beat 0, so use `to_q = lambda s: inv(s + clock(0))`.

- [ ] **Step 1: Write the failing tests** with a temp song dir, a fake `separate` that writes 1 s sine WAVs at 22050 Hz for the 4 stems, and a fake `transcribe`:
  - `test_writes_stems_and_midis`: `render` returns `[bass.mid, other.mid]`. All 4 `stems/*.wav` exist. `mido.MidiFile(bass.mid).tracks[1].name == "Bass"`, and the other file's track is named "Other".

  - `test_no_events_or_score_uses_120bpm`: no score.abc, no events.json → set_tempo is `mido.bpm2tempo(120)` and the output includes a "warning" line.
  - `test_negative_clock0_pads`: clock(0) = -0.25 s → `stems/drums.wav` is 0.25 s longer than raw, and starts with zeros.
